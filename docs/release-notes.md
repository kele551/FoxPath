狐径 FoxPath v1.2.2 — 面板上的仓库地址换成 GitHub，并且可以直接点开

## 下载

| 文件 | 说明 |
| --- | --- |
| `FoxPath.exe` | 主程序，绿色单文件，双击即用。版本号写在 exe 属性里（鼠标悬停 / 右键-属性-详细信息） |

## 这一版改了什么

### 1. 面板页脚：地址换成 GitHub，并且可以点

- 控制面板底部的作者一行，地址从已停更的 `gitcode.com/kele551/FoxPath` 换成
  **`github.com/kele551/FoxPath`**（国外镜像仓库，仍在更新）。
- 从纯文字改成**可点链接**：点一下直接用默认浏览器打开项目主页，不用再手动复制粘贴。
- 只改显示，**代理、IP 体检、吞吐挑 IP、在线升级这些功能一行没动**。

### 2. 升级通道照旧

- 升级源仍以 **GitCode** 为主（国内快），Gitee / GitHub 兜底；
- Ed25519 公钥验签不变：**验不过 / 缺签名 / 签名格式不对，一律拒绝并保留当前版本**；
- 签名私钥只在维护者机器上，绝不进程序、绝不进仓库。

## 已知边界（照旧）

- 运营商如果按 **SNI** 掐断（TLS 握手里能看到域名），本地代理帮不上忙 —— 只能换网络或换方案。
- 线路分钟级抖动期间，主站可能"通几秒、堵几十秒"，体检与吞吐挑 IP 会如实反映。
- 只代理 GitHub 相关域名；**不改 hosts、不改系统 DNS**，退出时还原系统设置。
- 控制面板只监听 `127.0.0.1`，接口已做 Host/Origin 同源校验。
