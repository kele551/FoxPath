## 下载

| 文件 | 说明 |
| --- | --- |
| `FoxPath.exe` | 主程序，绿色单文件，双击即用。版本号写在 exe 属性里（鼠标悬停 / 右键-属性-详细信息） |

## 这一版改了什么

### 1. 主升级源切到 GitCode（国内访问更快）
- 升级检查**优先走 GitCode**（国内），Gitee / GitHub 保留兜底；
- **下载地址优先 GitCode**，Gitee / GitHub 作镜像回退（`mirrors[]`，老版本自动忽略该字段）；
- 老用户通过原来的入口升级到本版后，自动切到 GitCode，无需重装、无需改配置。

### 2. 升级验签照旧
- Ed25519 公钥验签不变：**验不过 / 缺签名 / 签名格式不对，一律拒绝并保留当前版本**；
- 签名私钥只在维护者机器上，绝不进程序、绝不进仓库。

## 已知边界（照旧）

- 运营商如果按 **SNI** 掐断（TLS 握手里能看到域名），本地代理帮不上忙 —— 只能换网络或换方案。
- 线路分钟级抖动期间，主站可能"通几秒、堵几十秒"，体检与吞吐挑 IP 会如实反映。
- 只代理 GitHub 相关域名；**不改 hosts、不改系统 DNS**，退出时还原系统设置。
- 控制面板只监听 `127.0.0.1`，接口已做 Host/Origin 同源校验。
