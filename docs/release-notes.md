狐径 FoxPath v1.2.6 — 升级源收口纯 GitHub，输入法回车不再误触发

## 下载

| 文件 | 说明 |
| --- | --- |
| `FoxPath.exe` | 主程序，绿色单文件，双击即用。版本号写在 exe 属性里（鼠标悬停 / 右键-属性-详细信息） |

## 这一版改了什么

这一版是一批收口与规范修复，**没有新功能**。

### 1. 升级与地址源只认 GitHub

- 候选 IP 的官方来源去掉被动镜像兜底，只走 `api.github.com/meta` 与 `raw.githubusercontent.com`；
- 升级候选地址去掉被动镜像，只认 GitHub 主源；注释与打包说明里的地址一并改成 GitHub。

### 2. 面板显示按规范收口

- 字体栈前置规范西文族，中文保留雅黑 / 苹方兜底；
- 去掉面板背景的径向渐变，底色更干净。

### 3. 修中文输入法下回车误触发

在中文输入法组词还没完成时按回车，以前会被面板当成「启用 / 退出」按钮点下去；现在先判断输入法状态，组词期间的回车不触发动作。

### 4. 打包环境固定

打包统一用 Python 3.15.2 + PyInstaller 6.22.3，产物环境一致。

## 已知边界（说明白比藏着重要）

- 只代理 GitHub 相关域名；**不改 hosts、不改系统 DNS**，退出时还原系统设置。
- 控制面板只监听 `127.0.0.1`，接口已做 Host/Origin 同源校验；危险动作只接 POST。
- 线路本身质量会波动：同一台机器，故障时段「候选池反复全灭」，连未改动的旧版也打不开。本版能做到的是**不押坏地址、快速换边、把并发调对**，不能让线路本身变好。
- README 里的第三方徽章（shields.io）不经过狐径：本项目只代理 GitHub 自己的域名，不转发其他站点的流量。

## 校验与升级

- 升级源只走 **GitHub**（GitCode/AtomGit 为纯 Pull 被动镜像，不挂附件、不作下载源）；
- Ed25519 公钥验签不变：**验不过 / 缺签名 / 签名格式不对，一律拒绝并保留当前版本**；
- 签名私钥只在维护者机器上，绝不进程序、绝不进仓库。
