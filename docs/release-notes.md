## 这一版修了什么

### 1. 在线升级增加 Ed25519 公钥验签（安全加固）

- **为什么**：以前的升级校验只比 sha256，而 sha256 与安装包放在同一个升级源里——源被整体替换
  （例如仓库账号被盗、有人推了恶意 version.json + 恶意 exe）时，sha256 会一起被改，等于没验。
- **现在**：升级源 version.json 必须带一份同目录的 version.json.sig，客户端用**内置公钥**验签；
  **验签不过 / 缺签名 / 签名格式不对，一律拒绝并保留当前版本**，绝不"先替换再校验"。
- **密钥**：签名私钥只在维护者机器上（绝不进程序、不进仓库）；客户端只带 32 字节公钥（公开无妨）。
- **能力边界（如实说明）**：签名能防"升级源被篡改 / 中间人换包"，**防不了**"维护者机器上的私钥被偷"，
  也不等于 Windows 代码签名证书（那解决的是杀软误报，属另一件事）。
- **兼容性**：老版本不认识 .sig、只读 version.json，升级行为不受影响；本版起强制验签。

## 已知边界（照旧）

- 运营商如果按 **SNI** 掐断（TLS 握手里能看到域名），本地代理帮不上忙 —— 只能换网络或换方案。
- 线路分钟级抖动期间，主站可能"通几秒、堵几十秒"，体检与吞吐挑 IP 会如实反映。
- 只代理 GitHub 相关域名；**不改 hosts、不改系统 DNS**，退出时还原系统设置。
- 控制面板只监听 `127.0.0.1`，接口已做 Host/Origin 同源校验。
