狐径 FoxPath - 使用说明
作者: 海风（kele551）   https://gitee.com/kele551/FoxPath
版本看 exe 属性, 或控制面板标题
================================

它是什么:
  国内访问 github.com 时通时断。狐径不查 DNS, 也不改 hosts ——
  它自己拿着一批 GitHub 官方 IP 逐个实测握手, 挑当前能用的直连。
  本机代理 + PAC, 只接管 github.com 一个域名。
  不需要管理员权限, 不写 hosts, 不改系统 DNS。
  (手机流量能开、电脑宽带上不去, 多半就是本机解析到的那个 IP 不通)


1. 怎么用 (就一步)
   双击「FoxPath.exe」运行。
   - 会自动打开浏览器控制面板 http://127.0.0.1:8788/ui
   - 会自动把系统代理设成自带的 PAC, 接管这几个域名:
       github.com / www.github.com          (主站)
       raw.githubusercontent.com            (raw 文件, 例如各种一键脚本、配置文件)
       objects.githubusercontent.com        (GitHub 发布附件的下载)
     其中 raw / 附件走**专属 IP 池** (官方 185.199.108.0/22), 不会连错服务器。
     页面渲染用的头像与资源域 (avatars / camo / githubassets) 仍然直连 ——
     它们本来就通, 走代理反而会让页面样式脚本加载失败、按钮点不动。
   - 其他网站完全走原路线, 不受影响
   - 屏幕上看不到窗口是正常的: exe 没有控制台, 日志写在
     %LOCALAPPDATA%\FoxPath\foxpath.log
   - 首次启动请等 15 ~ 20 秒: 程序要并发体检 49 个候选 IP,
     体检完成前代理还没完全生效


2. 控制面板 (从上到下四块)

   [1] 版本与升级
       左边是当前版本, 中间一条箭头, 右边是新版本号 —— 没有新版时右边是「—」。
       - 检查更新   问一次升级源 (Gitee 优先, GitHub 兜底)
       - 立即升级   只在真有新版时才出现。点了之后的过程是:
                    下载新 exe → 校验 SHA256 → 交给一个独立小助手 →
                    旧程序退出并还原系统代理 → 覆盖 exe → 自动重启
                    下载时那条渐变进度条会走, 全程不用你手动换文件。
       升级失败会红字写明原因 (连不上升级源 / 校验不过 / 信息里没有下载地址),
       校验不过就放弃, 不会留下半成品。

   [2] 加速状态
       出口 IP      当前在用哪个 GitHub IP, 以及延迟
       加速状态     已启用 / 未启用
       上次体检     上一轮测完候选池的时间
       - 启用加速     把系统代理指向本程序 (PAC)
       - 停用并还原   手动关掉加速, 并把系统代理恢复成原来的样子
       - 立即重测     立刻重测一批官方 IP, 不用等 5 分钟那一轮
       - 开机自启     勾上 = 写当前用户的 HKCU Run, 下次登录自动后台启动
       - 退出并还原   安全退出, 并把系统代理恢复原状 (点之前会问一次)

   [3] 当前可用 IP
       按延迟排序的可用 IP 表, 每 5 分钟自动重测刷新。
       这栏一个都没有 = 当前线路一个候选都不通, 程序会自己重拉官方 IP 表
       并回退系统 DNS。反馈问题时把这栏的数字一起贴上, 定位快很多。

   [4] 日志
       就是 foxpath.log 的尾部, 自动滚到最新一行。


3. 工作原理
   - 本机监听 127.0.0.1:8787 作为 HTTP/HTTPS 代理
   - 代理 github.com / www.github.com / raw.githubusercontent.com /
     objects.githubusercontent.com, 其余域名 PAC 返回 DIRECT
   - 每 5 分钟并发重测候选池, 入选条件是 TCP 443 握手 + TLS 证书校验 +
     HTTP 首包必须 2xx/3xx (429 限流也算活着 —— 说明对面确实是 GitHub)
     (有些 IP 证书是对的, 但只服务 API/CDN, 访问首页返回 400, 必须滤掉)
   - 候选池从三个源依次同步官方 IP 段: api.github.com/meta -> Gitee 上的
     meta.json (国内三网都能拉; 联通/移动拉不到官方接口时的兜底) -> GitHub raw
   - 面板上的「线路体检」把可用数量、表源、最快 IP 列成一行, 点「复制诊断信息」
     就能直接发给作者定位问题; 自动探测全都不通时, 还能「手动指定 IP」救急
   - 候选全灭时依次自救: 重拉官方表 → 查系统 DNS → 放宽超时重测;
     三步都不通才回退系统解析 (等于没装本程序, 不会更糟)
   - 正常退出和开机自启的静默模式都会还原系统代理; 还原备份固定在
     %LOCALAPPDATA%\FoxPath\proxy-backup.json


4. 出过问题想自救
   程序被强杀、或者 exe 已经删了、但系统代理还指着 127.0.0.1:8788, 跑这一条收尾:

     FoxPath.exe --restore

   它只做一件事 —— 把本程序写进系统的 PAC 设置清掉; 不起代理、不开面板。


5. 打不开 GitHub 怎么办
   - 先看日志 %LOCALAPPDATA%\FoxPath\foxpath.log
   - 控制面板「当前可用 IP」那栏如果是空的, 说明当前线路一个候选 IP 都不通,
     程序会自动重拉官方 IP 表并回退系统 DNS (等于没装本程序)
   - 还是不行, 把「当前可用 IP」那栏的数字连同日志发到仓库 Issues


6. 卸载
   - 面板里点「退出并还原」
   - 勾了「开机自启」的, 再点一次取消 (会删掉 HKCU 注册表的 Run 项)
   - 本程序不写系统目录; 数据目录 %LOCALAPPDATA%\FoxPath\ 里只有日志和一份
     代理还原备份, 可以整个删掉
   - 最后删掉 exe 所在目录即可
   - 万一 exe 已经删掉、系统代理却还指着本程序, 用第 4 节那条 --restore 收尾


7. 版本号
   从 v1.0.3 起产物固定叫 FoxPath.exe, 文件名不带版本号;
   版本号写进 exe 属性 (鼠标悬停, 或右键 - 属性 - 详细信息), 控制面板标题上也写着。

   v1.0.5 — 2026-09-22  网页版在线升级: 检查更新 / 立即升级 / 进度条 / 校验后自动覆盖重启
   v1.0.4 — 2026-09-22  加作者署名 (源码头、控制面板底部、日志、exe 属性)
   v1.0.3 — 2026-09-22  重做图标; 产物改名 FoxPath.exe, 版本号写进 exe 属性
   v1.0.2 — 2026-09-22  程序已在后台时, 第二次双击改为直接打开正在运行的控制面板

8. 注意: 本目录里还有一个旧版的 Run-GitHubFix.bat
   - 那是**另一套做法**, 和上面这个 exe 无关: 它直接改系统 hosts 文件 + 装计划任务,
     需要管理员权限(会弹 UAC), 会修改 C:\Windows\System32\drivers\etc\hosts
   - 两套方案二选一, 别同时用; 只想用推荐方案的话, 不用理它
   - 如果之前跑过它, 用 Fix-GitHub.ps1 -Uninstall 收尾(会一并清理 hosts 里的自动段)

升级时请注意：
  升级完成后程序会**自动重新打开**。如果它没出现（个别杀毒软件会拦住升级后的
  第一次启动，实测火绒出现过这种情况），**双击一下 FoxPath.exe 就能正常使用**，
  升级本身是完成的。
  为什么：新版本的文件刚落地时，杀软要做一次"首次运行"检查，可能把第一次启动拦掉。
  程序退出前已经把系统代理还原好了，所以不会影响你上网、也不会让浏览器出错。
