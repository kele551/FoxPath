狐径 FoxPath v1.0.0 用法
=======================

1. 双击「狐径-v1.0.0.exe」运行
   - 会自动打开浏览器控制面板 http://127.0.0.1:8788/ui
   - 会自动把系统代理设成自带的 PAC(只影响 github.com / githubusercontent.com / githubassets.com)
   - 其他网站完全走原路线, 不受影响

2. 控制面板按钮
   - 启用加速 / 停用并还原：手动控制 PAC
   - 立即重测：立刻重测一批 GitHub 官方 IP
   - 开机自启：写入当前用户的 HKCU Run，下次登录自动后台启动
   - 退出并还原：安全退出，并把系统代理恢复成原来的样子

3. 工作原理
   - 本机监听 127.0.0.1:8787 作为 HTTP/HTTPS 代理
   - 只代理 GitHub 相关域名，其余域名 PAC 返回 DIRECT
   - 每 5 分钟重测一次 GitHub 官方 IP，挑能 TLS 握手 + HTTP 首包正常的写进候选表
   - 连接时优先用候选表里的 IP 直连；候选表全灭时，会重拉官方 IP 表并回退到系统 DNS

4. 卸载
   - 运行一次后点「退出并还原」
   - 勾了「开机自启」的话再点一次取消
   - 删除本目录即可，没有任何安装残留
